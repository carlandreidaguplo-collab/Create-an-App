# Team Directory App

A React application for browsing team members, searching user information, viewing individual member details, marking favorites, and switching between dark and light themes.

## Features

- Home, Users, About, and 404 pages using React Router.
- Search team members by information.
- View individual team member details.
- Add or remove favorites.
- Toggle between dark and light modes.
- Loading and empty states.

## Technologies Used

- React
- Vite
- React Router
- JavaScript
- CSS

## How to Run

1. Install dependencies using `npm install`.
2. Start the development server using `npm run dev`.
3. Open the local URL shown in your terminal.
